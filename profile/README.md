## Oathline

A person's yes to an AI agent means exactly what they saw or heard: Oathline binds an approval to the exact action it approved, and keeps a hash-chained record of who approved what.

- [**oathline**](https://github.com/oathline/oathline) (`pip install oathline`): the Core library.
- [**oathline-guard**](https://github.com/oathline/oathline-guard) (`pip install oathline-guard`): an MCP guard. Reads pass; every other tool call waits for a person's coded yes in a second terminal.
